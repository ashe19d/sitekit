Export to GitHub

SiteKit creates a repository in your GitHub account and uploads index.html, style.css, logo.svg and a README.md. You can then edit the code and publish it.

1. Connect GitHub

Create one at github.com/settings/tokens (classic: scope repo). A fine-grained token also works: all repositories, with Administration, Contents and Pages set to read and write. The token stays in this tab only, is never saved in your settings file and is never exported.
